# Penjelasan Langkah Pengujian

## 1. Black Box Testing

### Langkah 1

Membuka fitur yang akan diuji.

### Langkah 2

Memasukkan data uji sesuai test case.

### Langkah 3

Menjalankan proses pengujian tanpa melihat source code.

### Langkah 4

Membandingkan output sistem dengan expected result.

### Langkah 5

Mencatat hasil pengujian ke dalam dokumentasi GitHub.

---

## 2. White Box Testing

### Langkah 1

Menganalisis source code program.

### Langkah 2

Mengidentifikasi percabangan, perulangan, dan alur program.

### Langkah 3

Membuat Control Flow Graph (CFG).

### Langkah 4

Menghitung Cyclomatic Complexity.

### Langkah 5

Menentukan Independent Path.

### Langkah 6

Melakukan pengujian berdasarkan jalur yang telah dibuat.

### Langkah 7

Mendokumentasikan hasil pengujian ke GitHub.

---

## 3. Gray Box Testing

### Langkah 1

Mempelajari fungsi sistem dan sebagian struktur internal aplikasi.

### Langkah 2

Menganalisis hubungan antara database, session, dan aplikasi.

### Langkah 3

Melakukan pengujian menggunakan teknik Matrix Testing, Regression Testing, Pattern Testing, dan Orthogonal Array Testing.

### Langkah 4

Mencatat hasil pengujian dan membandingkannya dengan kebutuhan sistem.

### Langkah 5

Menyimpan seluruh hasil pengujian pada repository GitHub.

---

## Kesimpulan

Berdasarkan seluruh proses pengujian yang dilakukan, fitur Login Member, Registrasi Member, Login Admin, Kelola Member, dan Jadwal Gym telah berjalan sesuai kebutuhan sistem. Hasil pengujian menunjukkan bahwa sistem dapat berfungsi dengan baik baik dari sisi pengguna, logika program, maupun hubungan dengan database.
